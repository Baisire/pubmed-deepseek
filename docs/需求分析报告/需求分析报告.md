# 需求分析报告 - 医学 PubMed 检索 + DeepSeek 文献解读（Streamlit 方案）

> 项目编号：a6 | 编写日期：2026-07-30 | 技术方案：Python + Streamlit

---

## 一、项目背景

用户需要一套自动化医学文献调研工具，将 **PubMed（医学文献数据库）** 与 **DeepSeek（大语言模型）** 打通联动。用户输入医学研究关键词，系统自动检索 PubMed 权威文献，再由 DeepSeek 完成翻译、总结、观点提炼、综述整理，一站式完成科研文献调研。

本方案采用 Python + Streamlit 技术栈，实现医学文献自动化检索与 AI 解读。

### 核心痛点

| 痛点 | 现状 | 期望 |
|------|------|------|
| 手动检索效率低 | 逐篇在 PubMed 搜索、筛选、复制摘要 | 输入关键词自动批量检索 |
| 语言障碍 | 英文论文阅读理解慢 | AI 自动翻译为中文，保留术语对照 |
| 信息提炼困难 | 逐篇阅读摘要，手动整理要点 | AI 自动总结核心观点、实验结论 |
| 综述整理耗时 | 手动对比多篇文献差异 | AI 自动生成文献综述 |

## 二、功能需求

### 2.1 核心功能

| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| F1 | PubMed 文献检索 | 输入关键词，自动调用 PubMed E-utilities API 检索文献 | P0 |
| F2 | 文献信息提取 | 提取标题、作者、摘要、期刊、发表日期、DOI、PMID | P0 |
| F3 | 英文翻译 | DeepSeek 将英文摘要翻译为中文，保留医学术语对照 | P0 |
| F4 | 摘要总结 | 提炼每篇文献的核心观点、实验方法、结论 | P0 |
| F5 | 文献综述 | 对多篇文献进行对比分析，生成结构化综述报告 | P1 |
| F6 | 用户管理 | 登录认证、管理员后台、用量统计（Streamlit 方案新增） | P1 |
| F7 | 中英双语 | 界面支持中文/英文切换（Streamlit 方案新增） | P2 |

### 2.2 输入参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| keyword | String | 是 | - | 医学研究关键词，如 "myocardial infarction treatment" |
| max_results | Integer | 否 | 5 | 检索文献数量（3-10 篇，滑块选择） |
| analysis_type | String | 否 | summary | 分析模式：translate（翻译）/ summary（摘要）/ review（综述） |
| api_key | String | 是 | - | DeepSeek API Key（环境变量或侧边栏输入） |

### 2.3 输出格式

输出为 Markdown 格式的结构化文献调研报告，包含：

```
# 文献调研报告：{关键词}

## 检索概览
- 检索数据库：PubMed
- 检索关键词：{keyword}
- 检索结果：共 {count} 篇文献

## 文献详情

### 文献 1
- **标题**：{英文标题}
- **中文翻译**：{中文标题}
- **作者**：{作者列表}
- **期刊**：{期刊名称}
- **发表日期**：{日期}
- **PMID**：{PMID}
- **DOI**：{DOI}
- **摘要原文**：{英文摘要}
- **中文翻译**：{中文翻译摘要}
- **核心观点**：{AI 提炼的要点}

### 文献 2
...

## 综述分析（仅 review 模式）
- 研究趋势
- 方法对比
- 结论差异
- 研究空白
```

## 三、用户场景

### 场景 1：医学生文献调研
> 用户登录系统，输入 "diabetes mellitus type 2 treatment"，选择 summary 模式，获取 5 篇文献的中文摘要和核心观点。

### 场景 2：科研人员综述写作
> 用户登录系统，输入 "CRISPR gene therapy"，选择 review 模式，获取 10 篇文献的对比分析和综述报告，下载 Markdown 报告。

### 场景 3：临床医生快速了解
> 用户登录系统，输入 "hypertension guidelines 2024"，选择 translate 模式，获取最新指南文献的中文翻译。

### 场景 4：管理员管理客户
> 管理员登录后台，创建客户账号、查看用量统计、进行检索测试。

## 四、技术约束

| 约束 | 说明 |
|------|------|
| 技术栈 | Python 3.10+ / Streamlit / requests / openai SDK |
| 文献来源 | PubMed E-utilities API（免费，无需 API Key 即可使用，限 3 次/秒） |
| AI 模型 | DeepSeek（通过 OpenAI 兼容 SDK 调用） |
| 数据库 | SQLite（Python 内置 sqlite3，无需额外安装） |
| 预算 | <1k，仅需 DeepSeek API 调用费用 |
| 免费内容 | PubMed API 免费提供摘要，全文需 publisher 权限 |
| 部署环境 | 普通 PC 或最低配云服务器即可运行 |

## 五、验收标准

| 编号 | 验收项 | 验证方式 |
|------|--------|----------|
| A1 | 输入关键词能正确检索到 PubMed 文献 | 检查返回的文献 PMID 在 PubMed 官网可查 |
| A2 | 文献信息提取完整（标题、作者、摘要、日期） | 对比 PubMed 官网页面数据 |
| A3 | DeepSeek 翻译准确，医学术语保留对照 | 人工抽检 3 篇文献翻译 |
| A4 | 摘要总结涵盖核心观点 | 人工对比原文与总结 |
| A5 | 综述报告结构清晰、对比合理 | 人工阅读评估 |
| A6 | 应用可通过 `streamlit run app.py` 正常启动 | 实际运行测试 |
| A7 | 用户登录/登出功能正常 | admin/admin123 登录测试 |
| A8 | 管理员可创建客户、查看用量 | 管理后台操作测试 |
| A9 | 报告下载功能正常 | 下载 Markdown 文件并打开验证 |
| A10 | 中英双语切换正常 | 切换语言后界面文案更新 |

## 六、非目标（Out of Scope）

| 不做的事 | 原因 |
|---------|------|
| 获取论文全文 | PubMed 全文需 publisher 权限，超出范围 |
| 图片/表格提取 | API 仅返回文本，图片需另爬 |
| 实时文献监控 | 本项目为按需检索，非订阅推送 |
| 多数据库联合检索 | 仅 PubMed，不扩展其他数据库 |
| 多用户高并发 | SQLite 单写入，适合小团队使用 |
