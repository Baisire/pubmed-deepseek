## 二、PubMed E-utilities API 评估

### 2.1 API 概述

| 项目 | 说明 |
|------|------|
| 接口名称 | NCBI E-utilities |
| 基础 URL | `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/` |
| 认证 | 无需 API Key 即可使用（限 3 次/秒）；申请 API Key 后 10 次/秒 |
| 费用 | 免费 |
| 文档 | https://www.ncbi.nlm.nih.gov/books/NBK25501/ |

### 2.2 关键接口

#### esearch - 文献搜索

```
GET https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi
  ?db=pubmed
  &term={keyword}
  &retmax={max_results}
  &retmode=json
  &sort=relevance
```

返回示例：
```json
{
  "esearchresult": {
    "count": "15234",
    "idlist": ["38123456", "38123455", "38123454"]
  }
}
```

#### efetch - 文献详情

```
GET https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi
  ?db=pubmed
  &id={pmid1,pmid2,pmid3}
  &retmode=xml
  &rettype=abstract
```

返回 XML 格式，包含：PMID、标题、作者、摘要、期刊、日期、DOI。

### 2.3 频率限制

| 模式 | 限制 | 应对 |
|------|------|------|
| 无 API Key | 3 次/秒 | 本项目仅需 2 次 API 调用（esearch + efetch），不会超限 |
| 有 API Key | 10 次/秒 | 可在请求参数中加 `api_key` |

### 2.4 数据字段映射

| 目标字段 | XML 路径 | 说明 |
|---------|----------|------|
| PMID | `PubmedArticle/MedlineCitation/PMID` | 唯一标识 |
| 标题 | `PubmedArticle/MedlineCitation/Article/ArticleTitle` | 可能含子标签，用 itertext 拼接 |
| 摘要 | `PubmedArticle/MedlineCitation/Article/Abstract/AbstractText` | 可能有多个分段，带 Label 属性 |
| 作者 | `PubmedArticle/MedlineCitation/Article/AuthorList/Author` | 含 LastName, ForeName |
| 期刊 | `PubmedArticle/MedlineCitation/Article/Journal/Title` | 期刊全名 |
| 日期 | `PubmedArticle/MedlineCitation/Article/Journal/JournalIssue/PubDate` | 可含 Year/Month/Day |
| DOI | `PubmedArticle/MedlineCitation/Article/ELocationID` | ELocationIDType=doi |

### 2.5 风险与应对

| 风险 | 概率 | 影响 | 应对方案 |
|------|------|------|----------|
| 摘要缺失 | 中 | 部分文献无摘要 | 文献 abstract 字段为空字符串，报告中标注"暂无摘要" |
| Abstract 多段 | 中 | 摘要被拆分为 Background/Methods/Results 等 | 拼接所有 AbstractText，保留 Label 前缀 |
| API 超时 | 低 | 检索失败 | requests 设 timeout=30/60，异常返回空列表 |
| XML 解析异常 | 低 | 字段缺失 | 每个字段用 find + is None 判断，缺失返回空字符串 |
| ArticleTitle 含子标签 | 低 | 标题解析不完整 | 使用 itertext() 拼接所有文本节点 |

## 三、DeepSeek API 集成评估

### 3.1 调用方式

通过 OpenAI 兼容 SDK 调用 DeepSeek API，无需额外 SDK。

| 项目 | 说明 |
|------|------|
| SDK | openai>=1.0.0（OpenAI Python SDK） |
| Base URL | `https://api.deepseek.com` |
| 模型名称 | `deepseek-chat` |
| 认证 | API Key（环境变量 DEEPSEEK_API_KEY 或侧边栏输入） |
| 输入 | 文献数据（JSON 字符串）+ 分析类型 |
| 输出 | Markdown 格式的分析报告 |

### 3.2 提示词策略

根据 `analysis_type` 参数，使用不同的系统提示词（与 docs/提示词设计/ 一致）：

| 模式 | 提示词重点 | temperature | 输出 |
|------|-----------|-------------|------|
| translate | 逐篇翻译标题和摘要，保留医学术语对照 | 0.3 | 翻译报告 |
| summary | 提炼每篇文献的核心观点、方法、结论 | 0.4 | 摘要报告 |
| review | 跨文献对比分析，生成综述 | 0.5 | 综述报告 |

### 3.3 Token 预算

| 场景 | 输入 Token | 输出 Token | 说明 |
|------|-----------|-----------|------|
| 5 篇文献 translate | ~5,000 | ~5,000 | 每篇约 1,000 token |
| 5 篇文献 summary | ~5,000 | ~3,000 | 总结比翻译短 |
| 10 篇文献 review | ~10,000 | ~3,000 | 综述需综合分析 |
| maxTokens 设置 | - | 8,192 | 确保长报告不被截断 |

### 3.4 费用估算

| 项目 | 费用 | 说明 |
|------|------|------|
| DeepSeek API | ~0.01 元/次 | 5 篇文献约 10,000 token，DeepSeek 定价极低 |
| PubMed API | 免费 | E-utilities 无需付费 |

## 四、Streamlit 技术选型评估

### 4.1 技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| Web 框架 | Streamlit >= 1.30 | 零前端代码，自动渲染表单/按钮/Markdown |
| HTTP 请求 | requests >= 2.31 | 调用 PubMed E-utilities API |
| AI SDK | openai >= 1.0 | OpenAI 兼容 SDK 调用 DeepSeek |
| 数据库 | sqlite3（内置） | 用户管理 + 用量记录，无需额外安装 |
| XML 解析 | xml.etree.ElementTree（内置） | 解析 PubMed API 返回的 XML |

### 4.2 优势分析

| 优势 | 说明 |
|------|------|
| 零前端开发 | Streamlit 自动生成 Web UI，无需 HTML/CSS/JS |
| 依赖极简 | 仅 3 个 pip 包（streamlit, requests, openai） |
| 部署简单 | `streamlit run app.py` 一条命令启动 |
| 无平台依赖 | 不依赖钉钉等第三方平台 |
| 数据可控 | 数据仅经过自己的服务器 + DeepSeek API |
| 扩展灵活 | Python 生态任意扩展 |

### 4.3 局限性

| 局限 | 影响 | 应对 |
|------|------|------|
| SQLite 并发 | 多用户同时写入可能冲突 | 小团队使用无影响，如需高并发可换 PostgreSQL |
| 无异步 | Streamlit 同步执行 | 检索+分析通常 30-60 秒，用 spinner 提示等待 |
| 移动端适配 | Streamlit 移动端体验一般 | 主要面向桌面端使用 |

## 六、降级策略

| 场景 | 降级方案 |
|------|----------|
| PubMed API 不可用 | 返回错误提示，建议用户稍后重试 |
| DeepSeek API 不可用 | 提示检查 API Key，显示错误信息 |
| 文献无摘要 | 该文献 abstract 字段为空，报告中标注"暂无摘要" |
| 检索结果为 0 | 返回提示，建议用户更换关键词，给出英文关键词建议 |
| XML 解析失败 | 异常捕获，返回空列表 |
| DeepSeek 返回空内容 | 提示用户稍后重试 |
