# PubMed 文献检索 + DeepSeek 解读 - 使用说明

## 一、系统简介

本系统是基于 Python + Streamlit 的医学文献自动化检索与 AI 解读工具。用户输入医学关键词，系统自动检索 PubMed 权威文献，由 DeepSeek AI 完成翻译、摘要或综述分析，一站式完成科研文献调研。

系统内置客户管理功能，管理员可分配客户账号，客户登录后使用自己的 DeepSeek API Key 进行检索，系统自动记录每位客户的用量。

### 核心功能

| 功能   | 说明                           |
| ---- | ---------------------------- |
| 文献检索 | 自动调用 PubMed API，按关键词检索权威医学文献 |
| 英文翻译 | 将英文标题和摘要翻译为中文，保留医学术语对照       |
| 摘要总结 | 提炼每篇文献的研究目的、方法、发现、结论         |
| 文献综述 | 跨文献对比分析，生成结构化综述报告            |
| 原文查看 | 每篇文献可点击跳转 PubMed，可展开查看英文原摘要  |
| 客户管理 | 管理员分配账号，客户登录后使用自己的 API Key   |
| 用量追踪 | 记录每位客户的检索历史和用量统计             |
| 中英双语 | 界面支持中文/English 一键切换          |

### 部署架构

```
管理员部署到 Streamlit Community Cloud（免费）
    ↓
所有客户通过同一个 URL 访问
    ↓
管理员分配账号 → 客户登录 → 输入自己的 API Key → 检索文献
    ↓
系统自动记录每位客户的检索用量
```

## 二、安装与启动

### 2.1 本地运行（开发/测试）

**环境要求**：Python 3.10+，网络连接

```bash
cd streamlit
pip install -r requirements.txt
streamlit run app.py
```

浏览器自动打开 <http://localhost:8501。>

首次启动自动创建 SQLite 数据库 `pubmed_users.db`，并生成默认管理员账号。登录后请立即重置密码。

### 2.2 云端部署（生产环境，推荐）

详见本文档第七章「部署到 Streamlit Community Cloud」。

## 三、管理员使用指南

### 3.1 登录

1. 打开应用 URL，看到登录页面
2. 输入管理员账号和密码
3. 点击「登录」按钮

> 默认管理员账号在首次启动时自动创建。登录页不会显示账号信息。如忘记密码，需删除 `pubmed_users.db` 文件重新初始化（会丢失所有客户数据）。初始密码admin123

### 3.2 管理后台

管理员登录后进入管理后台，包含 4 个标签页：

#### 标签 1：客户管理

**添加客户**

1. 在「添加客户」表单中输入用户名和密码（密码至少 6 位）
2. 点击「创建」按钮
3. 创建成功后将客户账号告知客户

**查看客户列表**

- 页面下方显示所有客户，包含用户名、角色、状态、创建时间

**禁用/启用客户**

- 点击客户右侧的「禁用」/「启用」按钮
- 被禁用的客户无法登录系统

**删除客户**

- 点击客户右侧的「删除」按钮
- 管理员账号和当前登录账号不可删除
- 删除客户会同时清除该客户的用量记录

**重置密码**

1. 在「重置密码」区域选择客户
2. 输入新密码（至少 6 位）
3. 点击「重置密码」按钮

#### 标签 2：用量统计

显示所有客户的检索用量汇总表格：

| 字段   | 说明         |
| ---- | ---------- |
| 用户名  | 客户账号       |
| 角色   | 管理员/普通用户   |
| 状态   | 启用/禁用      |
| 检索次数 | 累计检索次数     |
| 文献数量 | 累计检索到的文献总数 |
| 最近检索 | 最后一次检索时间   |

#### 标签 3：最近检索

显示最近 20 条检索记录，包含用户名、关键词、分析模式、文献数量、检索时间。

#### 标签 4：检索测试

管理员可直接在此进行文献检索测试，功能与客户使用界面一致。需输入自己的 DeepSeek API Key。

### 3.3 登出

点击侧边栏底部的「登出」按钮退出管理后台。

## 四、客户使用指南

### 4.1 登录

1. 打开应用 URL，看到登录页面
2. 输入管理员分配的用户名和密码
3. 点击「登录」按钮

> 如无账号，页面会提示「请联系管理员分配」。

### 4.2 输入 API Key

登录后在侧边栏找到「DeepSeek API Key」输入框，填入你自己的 API Key。输入框默认为空，每次登录需重新输入（不会保存到数据库）。

获取方式：访问 <https://platform.deepseek.com/> 注册并创建 API Key。

### 4.3 检索文献

**第 1 步：输入关键词**

在侧边栏「关键词」输入框输入英文医学关键词，例如：

- `myocardial infarction treatment`（心肌梗死治疗）
- `diabetes mellitus type 2 treatment`（2型糖尿病治疗）
- `CRISPR gene therapy`（CRISPR基因治疗）

**第 2 步：选择参数**

- 文献数量：拖动滑块选择 3-10 篇
- 分析模式：下拉选择
  - **翻译**：英文摘要翻译为中文，保留术语对照
  - **摘要**：提炼每篇文献的研究目的、方法、发现、结论
  - **综述**：多篇文献跨文献对比，生成综述报告

**第 3 步：点击检索**

点击紫色「开始检索」按钮，等待 30-60 秒，主面板自动展示报告。

### 4.4 查看结果

- **文献列表**：每篇文献标题可点击跳转 PubMed 原文页面，下方显示 PMID、期刊、日期、DOI
- **英文摘要**：点击「查看英文原文摘要」展开查看完整 Abstract
- **AI 分析报告**：Markdown 格式渲染，包含翻译/摘要/综述内容
- **下载报告**：点击「下载报告」按钮保存为 .md 文件

### 4.5 查看检索历史

侧边栏底部「我的检索历史」展开后可查看自己的历史检索记录，包含时间、关键词、分析模式、文献数量。

### 4.6 语言切换

侧边栏顶部可选择界面语言：中文 / English。

### 4.7 登出

点击侧边栏底部的「登出」按钮。

## 五、常见问题

| 问题              | 原因              | 解决方案                    |
| --------------- | --------------- | ----------------------- |
| 登录提示失败          | 用户名或密码错误        | 检查输入，联系管理员重置密码          |
| 账号被禁用无法登录       | 管理员禁用了账号        | 联系管理员启用账号               |
| 检索结果为 0         | 关键词太窄或拼写错误      | 扩大关键词范围，检查拼写            |
| 部分文献无摘要         | PubMed 部分文献仅存标题 | 正常现象，报告会标注"暂无摘要"        |
| 执行超时            | 网络延迟或文献数量过多     | 减少 max\_results，重试      |
| 翻译不完整           | 输出 token 超限     | 减少 max\_results 至 3-5 篇 |
| DeepSeek API 报错 | API Key 无效或余额不足 | 检查 Key 正确性，确认账户余额       |
| 页面显示英文          | 界面语言设置为 English | 侧边栏顶部切换为「中文」            |
| 应用休眠打不开         | 云端 7 天无访问自动睡眠   | 等待 30 秒自动唤醒，或重新访问       |

## 七、部署到 Streamlit Community Cloud

### 7.1 前置条件

- GitHub 账号
- 代码已推送到 GitHub 仓库（当前仓库：<https://github.com/Baisire/pubmed-deepseek）>

### 7.2 部署步骤

1. 打开 <https://share.streamlit.io>
2. 使用 GitHub 账号登录
3. 点击「New app」，填写：
   - **Repository**：`Baisire/pubmed-deepseek`
   - **Branch**：`main`
   - **Main file path**：`app.py`
4. 点击「Deploy!」
5. 等待 1-2 分钟，部署完成后获得公网链接

链接格式：`https://baisire-pubmed-deepseek.streamlit.app`

### 7.3 部署后配置

1. 用默认管理员账号登录
2. **立即重置管理员密码**（在管理后台 > 客户管理 > 重置密码）
3. 添加客户账号
4. 将链接和账号发给客户

### 7.4 更新代码

本地修改代码后，推送到 GitHub。Streamlit Community Cloud 会自动检测更新，点击应用右上角「Rerun」即可生效。

### 7.5 注意事项

- 仓库必须为**公开**（Streamlit Community Cloud 免费版要求）
- 应用 7 天无访问会自动休眠，首次唤醒约 30 秒
- 资源限制：1GB RAM，适合 10-50 人使用
- 数据库存储在云端容器中，应用重新部署后数据会保留，但如果长时间不用被回收则可能丢失

## 八、技术说明

### 8.1 数据存储

- 数据库：SQLite，单文件 `pubmed_users.db`
- 密码加密：SHA256 + 随机 Salt
- 无需安装数据库服务，首次运行自动创建

### 8.2 API 调用

| API                | 用途    | 费用                    |
| ------------------ | ----- | --------------------- |
| PubMed E-utilities | 文献检索  | 免费                    |
| DeepSeek API       | AI 分析 | 按 token 计费，约 0.01 元/次 |

### 8.3 分析模式参数

| 模式        | Temperature | Max Tokens | 适用场景       |
| --------- | ----------- | ---------- | ---------- |
| translate | 0.3         | 8192       | 快速了解英文文献内容 |
| summary   | 0.4         | 8192       | 快速筛选有价值文献  |
| review    | 0.5         | 8192       | 文献调研、综述写作  |

## 九、注意事项

1. **API Key 安全**：每位客户使用自己的 DeepSeek API Key，Key 仅存储在浏览器会话中，不持久化到数据库，登出后自动清除
2. **文献来源**：所有文献来自 PubMed 官方数据库，可通过 PMID 在 <https://pubmed.ncbi.nlm.nih.gov> 查询原文
3. **AI 生成内容**：翻译和分析由 DeepSeek 生成，仅供参考，重要内容请核对原文
4. **免费内容**：系统仅获取文献摘要，不包含全文
5. **频率限制**：PubMed API 限制 3 次/秒，建议不要频繁连续运行
6. **数据备份**：云端部署时，建议定期在管理后台截图保存用量统计，以防容器回收导致数据丢失
