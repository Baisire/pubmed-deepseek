## 模块 2: search_pubmed() - PubMed 检索

| 属性 | 值 |
|------|-----|
| 文件 | app.py |
| 职责 | 调用 PubMed E-utilities API 检索文献，解析 XML 提取结构化数据 |
| 对应模块 | search_pubmed 函数 |

### 函数签名

```python
def search_pubmed(keyword: str, max_results: int = 5) -> list[dict]:
```

### 参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| keyword | str | - | 医学研究关键词 |
| max_results | int | 5 | 检索文献数量 |

### 返回值

```python
[
    {
        "pmid": "38123456",
        "title": "Effect of metformin on...",
        "abstract": "Background: ... Methods: ... Results: ...",
        "authors": "John Smith, Jane Doe",
        "journal": "New England Journal of Medicine",
        "pub_date": "2024 Jan 15",
        "doi": "10.1056/NEJMoa24012345"
    },
    ...
]
```

### 处理流程

```python
# 1. esearch 获取 PMID 列表
requests.get(f"{EUTILS_BASE}esearch.fcgi", params={
    "db": "pubmed", "term": keyword,
    "retmax": str(max_results), "retmode": "json", "sort": "relevance"
}, timeout=30)
# -> 解析 JSON -> id_list

# 2. efetch 获取文献详情（XML）
requests.get(f"{EUTILS_BASE}efetch.fcgi", params={
    "db": "pubmed", "id": ",".join(id_list),
    "retmode": "xml", "rettype": "abstract"
}, timeout=60)
# -> XML 字符串

# 3. ElementTree 解析 XML
root = ET.fromstring(xml_data)
for article_elem in root.findall(".//PubmedArticle"):
    # 提取 7 个字段（见下方字段解析表）
```

### XML 字段解析

| 字段 | XML 路径 | 解析方式 | 异常处理 |
|------|----------|----------|----------|
| pmid | `.//PMID` | `.text` | find 返回 None 则空字符串 |
| title | `.//ArticleTitle` | `itertext()` 拼接 | find 返回 None 则空字符串 |
| abstract | `.//AbstractText` | 遍历所有段，拼接 Label + text | 无 AbstractText 则空字符串 |
| authors | `.//Author` | 遍历，拼接 ForeName + LastName | 无作者则空字符串 |
| journal | `.//Journal/Title` | `.text` | find 返回 None 则空字符串 |
| pub_date | `.//PubDate` | 拼接 Year/Month/Day | find 返回 None 则空字符串 |
| doi | `.//ELocationID` | 遍历找 EIdType=doi | 无 DOI 则空字符串 |

## 模块 3: analyze_with_deepseek() - DeepSeek 分析

| 属性 | 值 |
|------|-----|
| 文件 | app.py |
| 职责 | 调用 DeepSeek API 对文献进行分析，返回 Markdown 报告 |
| 对应模块 | DeepSeek API 调用（OpenAI 兼容 SDK） |

### 函数签名

```python
def analyze_with_deepseek(
    articles: list[dict],
    keyword: str,
    analysis_type: str,
    count: int,
    api_key: str,
    lang: str = "zh",
) -> str:
```

### 参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| articles | list[dict] | - | search_pubmed 返回的文献列表 |
| keyword | str | - | 检索关键词 |
| analysis_type | str | - | 分析模式：translate/summary/review |
| count | int | - | 文献数量 |
| api_key | str | - | DeepSeek API Key |
| lang | str | "zh" | 界面语言，影响 user_prompt 语言 |

### 返回值

```python
"### 文献 1：...\n\n**基本信息**\n- PMID：...\n..."
```

### 模式配置

| 模式 | System Prompt 常量 | temperature | max_tokens |
|------|-------------------|-------------|------------|
| translate | SYSTEM_PROMPT_TRANSLATE | 0.3 | 8192 |
| summary | SYSTEM_PROMPT_SUMMARY | 0.4 | 8192 |
| review | SYSTEM_PROMPT_REVIEW | 0.5 | 8192 |

### API 调用

```python
client = OpenAI(api_key=api_key, base_url="https://api.deepseek.com")
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_prompt},
    ],
    temperature=config["temperature"],
    max_tokens=MAX_TOKENS,  # 8192
)
return response.choices[0].message.content
```

## 模块 4: _render_search() - 检索渲染

| 属性 | 值 |
|------|-----|
| 文件 | app.py |
| 职责 | 执行检索+分析+展示+下载+记录用量 |

### 函数签名

```python
def _render_search(s, lang, keyword, max_results, analysis_type, api_key):
```

### 执行流程

```
1. 边界检查: 空关键词 -> st.warning
2. 边界检查: API Key 缺失 -> st.error
3. st.spinner("正在检索 PubMed...")
   -> search_pubmed(keyword, max_results)
4. 边界检查: 结果为空 -> st.error + st.info
5. st.success("检索到 N 篇文献")
6. 展示文献列表（含 PubMed 链接 + 英文摘要折叠）
7. st.spinner("DeepSeek 正在分析文献...")
   -> analyze_with_deepseek(...)
8. 边界检查: API 异常 -> st.error
9. 边界检查: 空内容 -> st.error
10. st.markdown(report)  # 展示报告
11. st.download_button()  # 下载按钮
12. db.log_usage()  # 记录用量
```

|------|-----|
| 文件 | app.py |
| 职责 | 用户名密码输入，验证后写入 session_state |

### 执行流程

```
1. 侧边栏: 语言切换
2. 用户名输入 (st.text_input)
3. 密码输入 (st.text_input, type="password")
4. 登录按钮 -> db.verify_user(username, password)

6. 失败: st.error("用户名或密码错误")
```

## 模块 8: db.py - 数据库模块

| 属性 | 值 |
|------|-----|
| 文件 | db.py |
| 职责 | SQLite 用户管理 + 用量记录 |
| 数据库文件 | pubmed_users.db（自动创建在 app.py 同目录） |

### 数据表结构

#### users 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY | 自增 ID |
| username | TEXT UNIQUE | 用户名 |
| password_hash | TEXT | SHA256 哈希密码 |
| salt | TEXT | 随机盐值 |
| is_admin | INTEGER | 1=管理员, 0=普通用户 |
| is_active | INTEGER | 1=启用, 0=禁用 |
| created_at | TEXT | 创建时间 |

#### usage_log 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY | 自增 ID |
| user_id | INTEGER | 外键 -> users.id |
| keyword | TEXT | 检索关键词 |
| analysis_type | TEXT | 分析模式 |
| article_count | INTEGER | 文献数量 |
| created_at | TEXT | 检索时间 |

### 函数清单

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| init_db() | - | None | 建表 + 创建默认 admin/admin123 |
| create_user(username, password, is_admin) | str, str, bool | (bool, str) | 创建用户 |
| verify_user(username, password) | str, str | dict/None | 验证登录 |
| get_all_users() | - | list[dict] | 所有用户列表 |
| delete_user(user_id) | int | None | 删除用户及用量 |
| toggle_user_active(user_id, is_active) | int, bool | None | 启用/禁用 |
| reset_password(user_id, new_password) | int, str | (bool, str) | 重置密码 |
| log_usage(user_id, keyword, analysis_type, article_count) | int, str, str, int | None | 记录用量 |
| get_usage_by_user(user_id, limit) | int, int | list[dict] | 用户检索历史 |
| get_all_usage_stats() | - | list[dict] | 全员用量统计 |
| get_recent_usage(limit) | int | list[dict] | 最近检索记录 |

### 安全设计

| 机制 | 说明 |
|------|------|
| 密码哈希 | SHA256(salt + password)，每用户独立 salt |
| 盐值 | os.urandom(16).hex()，16 字节随机 |
| 密码长度 | 最少 6 位（create_user / reset_password 校验） |
| 账号禁用 | verify_user 检查 is_active，禁用账号无法登录 |

## 实施注意事项

1. **API Key 安全**：不可硬编码在代码中，通过环境变量或侧边栏输入
2. **超时设置**：esearch timeout=30s，efetch timeout=60s
3. **XML 解析**：使用 itertext() 处理含子标签的标题，拼接多段 AbstractText
4. **SQLite 路径**：DB_PATH 使用 `os.path.dirname(os.path.abspath(__file__))` 确保相对路径正确
5. **session_state**：登录状态、用户信息、语言偏好均存储在 session_state
6. **st.rerun()**：登录/登出/语言切换后需要 st.rerun() 刷新页面
