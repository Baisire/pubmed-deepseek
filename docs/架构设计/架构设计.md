## 二、模块对应关系

| 模块 | Streamlit 对应 | 说明 |
|-----------|----------------|------|
| Start 节点 (100001) | `st.sidebar` 输入组件 | Streamlit 自动渲染输入表单 |
| Code 节点 (200001) | `search_pubmed()` 函数 | 逻辑完全一致：esearch -> efetch -> XML 解析 |
| LLM 节点 (300001) | `analyze_with_deepseek()` 函数 | 复用相同 System Prompt，3 种模式 |
| End 节点 (900001) | `st.markdown()` + `st.download_button` | 直接在页面展示并支持下载 |
| 平台账号 | SQLite 用户管理 | 自主管理用户，无需平台依赖 |

| 模块 | 文件 | 职责 |

## 四、数据流

```
用户输入 (侧边栏)
  │ keyword (str)
  │ max_results (int, 3-10)
  │ analysis_type (str: translate/summary/review)
  │ api_key (str)
  │ lang (str: zh/en)
  ↓
_render_search()
  │
  ├──> search_pubmed(keyword, max_results)
  │      │
  │      │  1. requests.get(esearch) -> JSON -> id_list
  │      │  2. requests.get(efetch) -> XML
  │      │  3. ET.fromstring -> 遍历 PubmedArticle
  │      │  4. 提取 7 个字段: pmid, title, abstract, authors,
  │      │     journal, pub_date, doi
  │      │
  │      └──> list[dict]  # 文献字典列表
  │
  ├──> st.markdown()  # 展示文献列表（含 PubMed 链接）
  │
  ├──> analyze_with_deepseek(articles, keyword, analysis_type, count, api_key, lang)
  │      │
  │      │  1. MODE_CONFIG[analysis_type] -> system_prompt + temperature
  │      │  2. system_prompt.replace("{count}", str(count))
  │      │  3. articles_json = json.dumps(articles)
  │      │  4. user_prompt = STRINGS[lang]["user_prompt"].format(...)
  │      │  5. OpenAI client -> chat.completions.create(model="deepseek-chat")
  │      │
  │      └──> str  # Markdown 报告
  │
  ├──> st.markdown(report)  # 展示报告
  ├──> st.download_button()  # 下载按钮
  └──> db.log_usage(user_id, keyword, analysis_type, article_count)  # 记录用量
```

## 五、页面路由

```
main()
  │
  ├── db.init_db()  # 首次运行建表
  ├── 读取 session_state["lang"]
```

## 六、错误处理

| 函数 | 异常场景 | 处理方式 |
|------|---------|----------|
| search_pubmed | esearch 网络超时 | try/except 返回空列表 |
| search_pubmed | efetch 网络超时 | try/except 返回空列表 |
| search_pubmed | XML 解析失败 | try/except 返回空列表 |
| search_pubmed | 检索结果为 0 | id_list 为空时直接返回空列表 |
| search_pubmed | 文献无摘要 | abstract 字段为空字符串 |
| search_pubmed | ArticleTitle 含子标签 | 使用 itertext() 拼接 |
| search_pubmed | AbstractText 多段 | 拼接所有段，保留 Label 前缀 |
| analyze_with_deepseek | API 调用失败 | 异常抛出，由调用方 _render_search 捕获 |
| analyze_with_deepseek | 返回空内容 | _render_search 中检查并提示 |
| _render_search | 空关键词 | st.warning 提示 |
| _render_search | API Key 缺失 | st.error 提示 |
| db.verify_user | 用户不存在 | 返回 None |
| db.verify_user | 密码错误 | 返回 None |
| db.verify_user | 账号禁用 | 返回 None |

## 七、国际化设计

应用支持中英双语，通过 `STRINGS` 字典管理界面文案：

```python
STRINGS = {
    "zh": { "title": "...", "keyword_label": "...", ... },
    "en": { "title": "...", "keyword_label": "...", ... }
}
```

语言选择存储在 `session_state["lang"]`，切换时 `st.rerun()` 刷新页面。

DeepSeek 的 user_prompt 也跟随语言设置，确保 AI 输出语言与界面一致。
